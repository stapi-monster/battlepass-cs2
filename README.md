# Установка [BP] Web Quests CORE

Для работы нужен ключ лицензии и сервер, добавленный в личный кабинет на [api.cspoint.cc](https://api.cspoint.cc). ЕСЛИ НЕ ЗАГРУЖАЕТСЯ - ИСПОЛЬЗУЙТЕ VPN

**Порядок:** Авторизоваться на сайте → получить ключ → добавить сервер на сайте → поставить плагин → вписать ключ и БД → перезапустить сервер.

---

## 1. Получите ключ лицензии

1. Откройте [api.cspoint.cc](https://api.cspoint.cc) и нажмите **«Войти через Discord»**.
   Сразу после входа кабинет пустой: это нормально.
2. Напишите в Discord @stapi и сообщите, что вошли на сайт.
3. Автор выдаст вам ключ + лицензию на плагин, и он появится в кабинете.
4. **Ключ** (64 символа) автор пришлёт в личные сообщения Discord.

> Никому не передавайте ключ: он работает только на серверах из вашего кабинета.
> Если ключ утёк, попросите автора выпустить новый: старый сразу перестанет работать.

## 2. Добавьте сервер на сайте

1. В кабинете найдите карточку **BattlePass**.
2. В поле **«IP:порт»** введите адрес сервера, по которому к нему подключаются игроки, например `195.200.223.26:27015`.
3. Нажмите **«Добавить»**.

- По умолчанию можно добавить **5 серверов**. Нужно больше — напишите автору.
- После удаления сервера следующее удаление станет доступно через 12 часов. Проверяйте адрес перед добавлением.
- Напротив сервера видно, работает ли он и какая версия плагина стоит. Статус «работает» появится после запуска сервера с ключом.

## 3. Поставьте плагины на сервер

Сначала должны стоять:

| Что | Зачем |
|---|---|
| **Metamod build 1411** | Плагин работает только на этой версии |
| [cs2-menus](https://github.com/Pisex/cs2-menus) (Pisex)| Меню |
| [sql_mm](https://github.com/zer0k-z/sql_mm) | Подключение к БД сайта |
| cs2-client_cookies *(необязательно)* | Сохраняет личные настройки игроков |

Затем распакуйте в папку `game/csgo/` сервера:

1. **`battlepass.zip`** — ядро:
   ```
   addons/plugins/battlepass.so
   addons/configs/battlepass/settings.ini, commands.ini, menu.ini, notify.ini
   addons/translations/battlepass.phrases.txt
   ```
2. **`battlepass-modules.zip`** — модули. Без `bp_events` не засчитываются убийства, раунды, бомба и прочее, поэтому ставьте его всегда:

   | Модуль | Что делает |
   |---|---|
   | `bp_events` | Игровые события для заданий |
   | `bp_playtime` | Время в игре |
   | `bp_top` | Топ сезона, `!bptop` |
   | `bp_boosts` | Множители: Premium и бусты |

   Ненужный модуль можно просто удалить.

> При обновлении плагина не перезаписывайте свои настроенные `.ini`. Заменяйте только `battlepass.so`, модули и `battlepass.phrases.txt`.

## 4. Настройте

### Подключение к БД сайта

Файл `addons/configs/databases.cfg`. Добавьте секцию `"battlepass"`, данные те же, что у сайта
(Админ-панель сайта → БД → Свой мод → BattlePass):

```
"Databases"
{
	"battlepass"
	{
		"host"		"IP сервера БД"
		"database"	"имя базы"
		"user"		"пользователь"
		"pass"		"пароль"
		"port"		"3306"
	}
}
```

Пользователю БД нужен доступ с IP игрового сервера.

### Ключ и сайт

Файл `addons/configs/battlepass/settings.ini`:

```
"license_key"	"ваш ключ из Discord"
"server_id"		"1"
"site_url"		"https://ваш-сайт/battlepass"
```

- `license_key` — ключ из шага 1, без пробелов и переносов.
- `server_id` — ID этого сервера на вашем сайте: Боевой пропуск → Серверы, колонка ID. При `0` прогресс не записывается.
- `site_url` — ссылка на страницу пропуска. Игроки увидят её в чате, ппанораме: там они забирают награды.

### Окно пропуска на экране (Panorama)

У пропуска своё окно: уровень и опыт, вкладки «День / Неделя / Сезон / Топ / Настройки», полоска прогресса у каждого задания и свои уведомления. Оно открывается по `!bp` у всех игроков, какой бы тип меню ни был выбран в cs2-menus.

1. Возьмите из архива папку `workshop_addon/panorama/` и положите её в свой аддон CS2 Workshop Tools (`content/csgo_addons/<аддон>/panorama/...`).
2. Скомпилируйте аддон и загрузите его в мастерскую. Подключите его на сервере, чтобы игроки скачивали его при входе.
3. В `menu.ini` должно стоять `"panorama_ui" "1"` (так по умолчанию).

Нужен cs2-menus. Если его нет, работают обычные меню cs2-menus.
Цвета окна меняются в `panorama/styles/custom_game/battlepass_ui.css` (блок `@define` в начале), после правки аддон нужно скомпилировать заново.

## 5. Запустите и проверьте

Перезапустите сервер. Когда он загрузится, в консоли появится одно из двух:

```
==== BATTLEPASS LICENSE CONFIRM ====
```
Всё работает. Зайдите на сервер и напишите `!bp`.

```
==== BATTLEPASS ERROR LICENSE ====
```
Плагин не запустился. Причина записана в общий лог ошибок плагинов `addons/logs/error_<дата>.txt` (строка с `[BATTLEPASS] ERROR LICENSE`):

| Сообщение в логе | Что делать |
|---|---|
| `license_key is empty` | Впишите ключ в `settings.ini` и перезапустите сервер |
| `invalid license_key` | Ключ скопирован с ошибкой. Скопируйте его из Discord заново, целиком |
| `this server ip:port is not added` | Добавьте сервер на сайте (шаг 2). Порт должен совпадать с портом сервера |
| `license_key is for another plugin` | Это ключ от другого плагина |
| `license revoked` / `license expired` | Напишите автору |
| `license server unreachable` | Сервер не может достучаться до api.cspoint.cc. Проверьте, что хостинг разрешает исходящие HTTPS-запросы |

**Сервер добавлен, но всё равно «not added»?** Значит, хостинг выходит в интернет с другого IP.
В кабинете под карточкой появится жёлтый блок «Ключ проверялся с адресов, которых нет в списке».
Добавьте адрес оттуда или напишите автору.

**Сайт лицензий временно недоступен?** Ничего страшного: плагин продолжит работать до 48 часов по последней успешной проверке.
Ключ проверяется при запуске и затем раз в час.

## Команды

| Команда | Что делает |
|---|---|
| `!bp` | Меню заданий |
| `!bptop` | Топ сезона (модуль `bp_top`) |
| `!bpsettings` | Личные настройки игрока |
| `mm_bp_reload` | Перечитать конфиги (консоль сервера) |
